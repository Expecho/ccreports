  6. 6

    Avoid rebuilding the prompt cache

    medium impact · $82.30 at stake

    60 times a session re-read its context without a cache hit, costing $82.30 more than cache reads: 41 after a pause longer than the cache lifetime (avg 173k tokens reprocessed, $49.72); 12 without a pause, when something early in the conversation changed (avg 246k tokens reprocessed, $22.64); 7 after a model switch (avg 205k tokens reprocessed, $9.94).

    The main conversation's cache lasts 5 minutes with an API key or cloud provider and 1 hour on a Claude subscription; the promptCacheTtl setting (5m or 1h) chooses it, and 1-hour cache writes cost more. Before you continue a large conversation after a break, /compact it (or /clear for unrelated work) so a smaller context is rebuilt; /usage shows whether the cache is still warm. A miss without a pause means the start of the prompt changed. With tool search on (the default on supported models) MCP servers connecting mid-session no longer do this; with it off, servers connecting or tools being removed mid-session do, so keep the tool set stable during a conversation. Each model has its own cache: switching with /model mid-conversation re-reads the whole history. Pick the model at the start, or /compact before you switch.
